# 長城鈦金名人堂分會・例會排位系統

單一檔案網頁應用(index.html),無需安裝、無需 build,開啟即用。
資料(本週資訊、會員名單、上週分桌紀錄、儲存的座位表)儲存在 Supabase,並在目前瀏覽器保留備份。
座位圖與例會資料、來賓簽到表、來賓名牌可一鍵同步下載成 PNG 圖檔;「儲存紀錄」頁籤可瀏覽或刪除歷次存檔。
名單管理可設定 2 位傳 Mic 手；排位時會避開來賓桌，並依例會日期輪換至不同角落。

## 使用權限與資料週期
- 全站需使用管理員帳號登入；密碼由 Supabase 伺服器驗證，網站原始碼不含明碼密碼。
- 登入後的裝置共用同一份資料，約每 5 秒同步一次；多人同時修改同一項資料時，以最後儲存的內容為準。
- 來賓照片只保留在上傳照片的瀏覽器，不會上傳雲端。
- 本週輸入資料於**每週三上午 10:00** 後自動恢復空白(名單與儲存紀錄不受影響)。

## 部署方式

網站由 GitHub Pages 部署：

https://vi-chang.github.io/seat-CHANGCHENG/

雲端資料庫設定與權限規則位於 `supabase/`；更新資料庫時需先連結正確的 Supabase 專案，再套用 migrations。

## 注意事項
- 網路中斷時畫面會保留本機資料並顯示連線異常；恢復連線後再繼續編輯，避免離線內容與他人修改互相覆蓋。
- Supabase publishable key 可放在公開網頁中；資料表已啟用 RLS，讀寫必須通過伺服器端密碼驗證函式。
